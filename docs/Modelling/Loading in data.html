Why loading data matters for modelling

Before you fit a model, you must make sure the data is loaded correctly and is in the right format. If the input data is wrong, any model you fit may give misleading results.

For modelling, the key checks are:

  • the dataset has the expected rows and columns,
  • each column is the right type (numeric, factor, character),
  • missing values are handled appropriately,
  • categorical variables are encoded correctly,
  • any transformations needed for the model are prepared beforehand.

You can load a CSV file using the base R function read.csv().

# Load data from a local file in the Data folder

Identify variable types

For modelling, it is important to distinguish between numeric and categorical variables.

Code 
```{r}
# Example of converting a column to a factor
if ("Variety" %in% names(df)) {
  df$Variety <- as.factor(df$Variety)
}

# Confirm column types again
sapply(df, class)
```

If a variable contains categories such as group labels, season names, or treatment types, convert it to a factor before fitting a model.

Preparing data for a linear model

Remove or flag missing values

Different modelling functions handle missing values differently. For a simple model, remove rows with missing values or use explicit imputation.

Code 
```{r}
# Remove rows that contain any missing values
dfClean <- na.omit(df)

# Confirm no missing values remain
colSums(is.na(dfClean))
```
Variety   Block    SIZE   YIELD 
      0       0       0       0

Create model-ready variables

Some variables need transformation before modelling.

Code 
```{r}
# Example: if a numeric variable is stored as text, convert it explicitly
if ("Yield" %in% names(dfClean)) {
  dfClean$Yield <- as.numeric(dfClean$Yield)
}

# Example: create a new variable for a model
if ("SoilQuality" %in% names(dfClean)) {
  dfClean$highQuality <- dfClean$SoilQuality > 7
}
```
Warning

Always check the output of conversions such as as.numeric() because invalid text values can become NA silently.

Quick modelling check

A final modelling check should confirm the data is ready for lm() or similar functions.

Code 
```{r}
# Example using a simple linear model if the variables exist
if (all(c("Yield", "Nitrogen") %in% names(dfClean))) {
  mod <- lm(Yield ~ Nitrogen, data = dfClean)
  summary(mod)
}
```

This is a useful way to verify that the data types and values are appropriate for the model.
